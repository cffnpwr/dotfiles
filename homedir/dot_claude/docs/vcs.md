# バージョン管理

VCS操作の方針。

## 基本方針

- VCS操作はjjをデフォルトとする。
- リポジトリルートに `.jj` が無い場合のみgitを使う。
- `.jj` と `.git` の併存（colocated）でもjjを使う。
- 読み取り専用の確認（status・log・diff等）もjjを優先する。
- コマンド変換に迷う場合、VCSリファレンス系のスキルがあれば使う。

## コミットの粒度

- 1コミットには1つの性質の変更だけを入れる。改名と仕様変更、計測用の追加と本体の修正を混ぜない。

## コミットメッセージ

- Conventional Commitで1行で書く。
- 変更内容を書く。作業の契機（レビュー対応など）を内容の代わりに書かない。
- gitmojiは任意。
- 1行で表現できない・抽象的になりすぎる場合は、コミットのスコープが過大。
